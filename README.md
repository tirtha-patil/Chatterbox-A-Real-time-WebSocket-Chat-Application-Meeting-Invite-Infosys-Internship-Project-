Chatterbox – Real Time WebSocket Chat

A real-time chat application built using **FastAPI and WebSockets**.

## Features

- Real-time messaging
- Multiple chat rooms
- Typing indicators
- Join/leave notifications
- Clean UI

## Tech Stack

Backend:
FastAPI
WebSockets
Python

Frontend:
HTML
CSS
JavaScript

## Run Locally

Install dependencies

pip install fastapi uvicorn

Run server

python main.py

Open browser

http://localhost:8000
